# kayiranlar-stok

Kayıranlar Otomotiv için stok takip sistemi arayüz demosu.

- Tek dosyalık (`index.html`), tarayıcıda çalışır; sunucu ve veritabanı yoktur.
- Tüm veriler uydurma örnek veridir. Girilen veriler yalnızca kullanıcının kendi tarayıcısında kalır.
- Gerçek sistem ayrı geliştirilecektir; bu depo yalnızca ekran/akış önizlemesidir.
